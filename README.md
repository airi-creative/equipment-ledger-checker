# 備品台帳チェッカー（equipment-ledger-checker）

備品台帳（CSV）の異常を自動で検出する Python 製の小さなツールです。
標準ライブラリのみで動作します。

## 概要

現場の備品管理では、台帳の「返却予定日を過ぎても未返却」「必須項目の空欄」
「備品ID の重複」「日付の入力ミス」といった異常に気づくのが遅れがちです。
このツールは CSV を読み込み、異常を一覧化した Markdown レポートを出力します。

## 使い方
コマンド：`py ledger_check.py sample_ledger.csv`
実行すると、同じフォルダに `anomaly_report.md` が生成されます。
台帳 CSV は「備品ID,名称,現場,担当,貸出日,返却予定日,返却日」の形式を想定しています。
日付は YYYY-MM-DD 形式です。

## 検出する異常

1. 返却予定日を過ぎているのに未返却
2. 必須項目（備品ID／名称／現場）の欠落
3. 備品ID の重複
4. 日付フォーマットの不正

## サンプルデータ

`sample_ledger.csv` はテスト用のサンプルデータです（実データではありません）。
異常が検出されるケースを含んでいます。
